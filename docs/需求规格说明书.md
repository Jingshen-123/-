# 需求规格说明书 — 中文语序调整器

## 1. 项目概述

一个 Windows 桌面应用，帮助用户整理中文文本：调整语序、删除啰嗦表述，输出流畅的精炼文本。

## 2. 目标用户

需要润色中文文字的用户，如日常写作、工作汇报、邮件沟通等场景。

## 3. 功能需求

### 3.1 文本输入
- 用户在输入框中输入或粘贴中文文本
- 输入框支持多行文本
- 输入框有 placeholder 提示文字

### 3.2 文本润色
- 用户点击「润色」按钮触发处理
- 系统将文本发送至 DeepSeek API 进行以下处理：
  - 调整语序使其符合正确的中文表达习惯
  - 删除啰嗦、重复的表述
  - 保持原文语义完整不变
- 处理结果展示在输出框中

### 3.3 结果操作
- **复制**：一键复制输出框内容到剪贴板
- **清空**：一键清空输入框和输出框

### 3.4 API Key 管理
- 提供设置弹窗，用户可输入和修改 DeepSeek API Key
- API Key 加密存储到本地配置文件
- 未设置 API Key 时，点击润色会引导用户进行设置
- 脱敏显示已保存的 Key（如 sk-****....abcd）

### 3.5 状态反馈
- 处理中显示加载状态
- 错误时显示具体错误信息（无 Key、网络错误、API 异常等）
- 成功后状态栏显示完成提示

## 4. 用户场景

| 场景 | 流程 |
|------|------|
| 首次使用 | 打开应用 → 点击润色 → 提示设置 API Key → 进入设置页输入 Key → 保存 → 返回主界面润色 |
| 日常使用 | 粘贴文本 → 点击润色 → 等待处理 → 查看结果 → 复制使用 |
| 修改 Key | 点击设置 → 修改 Key → 保存 |

## 5. 验收标准

- [ ] 窗口可正常启动、缩放、全屏
- [ ] 未设 Key 时点击润色弹出设置引导
- [ ] 设置 Key 后可正常调用 API 润色文本
- [ ] 润色结果语义正确，语序通顺，无啰嗦内容
- [ ] 复制和清空功能正常
- [ ] 错误场景（断网、Key 无效等）有友好提示
