# 开发步骤 — 中文语序调整器

> 本文档是权威执行版本，与 `实施计划.md` 保持同步。

## 执行原则

1. **一次只做一个阶段**，完成后验证通过再继续
2. **不要跨阶段开发**——后续阶段的依赖必须等前面完成
3. **每个阶段结束更新 dev_logs/** 开发日志
4. 遇到问题先记录到日志，再排查

---

### 任务

### 接口定义
```python
class PolishError(Exception): ...

```

### System Prompt 要点
- 调整语序使其符合正确的中文表达习惯

## 阶段六：主窗口组装

### 任务
- 实现 `ui/main_window.py`

### 组件清单
- 输入框（QTextEdit）
- 输出框（QTextEdit，只读）
- 润色按钮（主按钮）
- 清空按钮（次要按钮）
- 复制按钮（次要按钮）
- 设置按钮（打开 settings_dialog）
- 状态栏（处理中/成功/错误）

### 交互逻辑
1. 点击润色 → 检查 Key → 有则调用 API，无则打开设置
2. 处理中 → 按钮 disabled + 状态栏"正在润色..."
3. 成功 → 结果显示 + 状态栏"润色完成"
4. 失败 → 状态栏显示具体错误
5. 清空 → 清空输入框和输出框
6. 复制 → 复制输出框内容到剪贴板

### 产出文件
- `ui/main_window.py`

### 验证
启动主窗口，完整走通：设 Key → 输入文本 → 润色 → 复制 → 清空。同时验证异常场景。
