# 设计规范 — 中文语序调整器

## 1. 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#0d0d0d` | 窗口底色 |
| 次级背景 | `#1a1a1a` | 控件背景 |
| 输入框背景 | `#1e1e1e` | 输入/输出区域 |
| 边框色 | `#2a2a2a` | 默认边框 |
| 边框聚焦 | `#00d4ff` | 获得焦点时高亮 |
| 主文字 | `#e0e0e0` | 正文 |
| 次要文字 | `#888888` | placeholder/提示 |
| 强调色 | `#00d4ff` | 按钮、高亮 |
| 强调色 hover | `#00b8e6` | 鼠标悬停 |
| 成功色 | `#00c853` | 操作成功 |
| 错误色 | `#ff5252` | 错误提示 |
| 警告色 | `#ffab00` | 警告提示 |

## 2. 字体规范

| 层级 | 字体 | 大小 | 粗细 |
|------|------|------|------|
| 窗口标题 | Microsoft YaHei | 14px | Bold |
| 按钮文字 | Microsoft YaHei | 13px | Normal |
| 输入/输出文字 | Microsoft YaHei | 14px | Normal |
| 状态栏 | Microsoft YaHei | 12px | Normal |
| placeholder | Microsoft YaHei | 14px | Normal (italic) |

## 3. 间距规范

| 元素 | 间距 |
|------|------|
| 窗口内边距 | 20px |
| 组件间距（垂直） | 12px |
| 按钮间距 | 10px |
| 输入框/输出框最小高度 | 200px |
| 按钮内边距 | 10px 24px |
| 圆角半径 | 6px |

## 4. 按钮样式

### 主按钮（润色）
- 背景：`#00d4ff`
- 文字：`#000000` 黑色
- 圆角：6px
- Hover：背景变亮 `#00e5ff` + 轻微发光阴影
- Pressed：背景 `#00b8e6`
- Disabled：背景 `#333333` 文字 `#666666`

### 次要按钮（清空、复制）
- 背景：透明
- 边框：1px `#444444`
- 文字：`#cccccc`
- Hover：边框 `#00d4ff` + 文字 `#00d4ff`
- Pressed：背景 `#1a1a1a`

### 设置按钮
- 图标风格：齿轮 icon
- 颜色：`#888888`
- Hover：`#00d4ff`

## 5. 输入/输出框

- 背景：`#1e1e1e`
- 边框：1px `#2a2a2a`
- 圆角：6px
- 内边距：12px
- 文字颜色：`#e0e0e0`
- 选中高亮：`#00d4ff` 透明度 30%
- Focus 边框：`#00d4ff`
- 只读状态（输出框）：背景略深 `#181818`

## 6. 状态栏

- 背景：`#111111`
- 高度：28px
- 文字：`#888888`
- 成功状态：`#00c853`
- 错误状态：`#ff5252`

## 7. 滚动条

- 宽度：8px
- 轨道背景：`#1a1a1a`
- 滑块背景：`#444444`
- 滑块 Hover：`#555555`
- 圆角：4px

## 8. 窗口规格

- 默认尺寸：900 x 700
- 最小尺寸：600 x 450
- 支持自由缩放和全屏
